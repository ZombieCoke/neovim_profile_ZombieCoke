# neovim_profile_ZombieCoke

Personal Neovim configuration based on [LazyVim](https://github.com/LazyVim/LazyVim), tuned for Rust development.

## Highlights
- LazyVim with Rust toolchain: rust-analyzer, rustaceanvim, crates.nvim, codelldb
- NvimTree file explorer, Onedark Pro theme
- Window navigation with Ctrl-h/j/k/l across Vim and Tmux

## Usage
Clone to ~/.config/nvim and launch nvim; lazy.nvim installs all plugins on first start.
